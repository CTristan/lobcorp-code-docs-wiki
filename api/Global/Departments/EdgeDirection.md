# Enum EdgeDirection
**Namespace:** [Global](/api/Global)
**Assembly:** Assembly-CSharp.dll

```csharp
public enum EdgeDirection
```
The direction along an edge ([`MapEdge`](/api/Global/Map/MapEdge)). `FORWARD` goes from `node1` to `node2`, and `BACKWARD` goes from `node2` to `node1`.
| Name | Value | Description |
| --- | --- | --- |
| FORWARD | 0 | `node1`→`node2`|
| BACKWARD | 1 | `node2`→`node1`|
