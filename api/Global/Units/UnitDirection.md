# Enum UnitDirection
**Namespace:** [Global](/api/Global)
**Assembly:** Assembly-CSharp.dll

```csharp
public enum UnitDirection
```

A facing direction for a unit.

`ELEVATOR` is used by Rabbit Protocol portals connected to elevators, such as the one from Information Department to Central. (See also [`RabbitManager::CreateRabbitSquad`](/api/Global/Rabbits/RabbitManager#createrabbitsquadsefiraenum-int)).

| Name | Value | Description |
| --- | --- | --- |
| LEFT | 0 | Facing left. |
| RIGHT | 1 | Facing right. |
| OTHER | 2 | Default value for neither direction.. |
| ELEVATOR | 3 | Special value for nodes connected to elevators.|
