# <img src="spaghetticorp.svg" height="40em" alt="Spaghetti Corp Logo"> LobCorp Code Docs Wiki

A Wiki.js project for documenting the scripts and systems of Project Moon's Lobotomy Corporation.

## What is this for?

This project aims to provide mod developers with a description and explanation of the source code for Lobotomy Corporation. This is a backing repository for the [LobCorp Code Docs](https://lobcorp.hemocode.dev/) Wiki.js website.
