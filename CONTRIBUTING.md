# Contributing

This wiki documents Lobotomy Corporation's scripts and systems for mod developers. If you know the codebase and want to contribute, ping lomour on the [Lobotomy Corp MOD Community Discord server](https://discord.gg/M74rB3uPk5), or edit pages directly in Wiki.js.

## Licensing

This wiki is licensed under the [MIT License](LICENSE). By contributing, whether you edit a page in Wiki.js or open a pull request on GitHub, you agree that your contributions are licensed under those same MIT terms.

We ask for this because the prose here gets redistributed. The hand-authored docs are packaged and republished as generated code documentation for mod developers, so every page has to carry a license that permits that. MIT also matches the rest of the open-lobotomy ecosystem, which keeps one license across the whole org.
